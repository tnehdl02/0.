# Binance Phone Scanner (Android, no server)

안드로이드 휴대폰에서 바이낸스 USDT 무기한 선물 종목을 직접 검사하는 앱입니다. 별도 서버나 Binance API 키가 필요하지 않습니다. 휴대폰의 Wi-Fi 또는 모바일 데이터를 사용합니다.

## 감시 조건

한국 시간 기준 매시간 `HH:50`에 전체 거래 가능 USDT 무기한 선물 종목을 검사합니다.

1. 현재 진행 중인 1시간봉의 **고가가 시가 대비 +5% 이상**
2. 현재 진행 중인 1시간봉의 **현재가가 시가 대비 +4% 이상**
3. 현재 진행 중인 1시간봉의 누적 거래량이 **직전 완료된 1시간봉 거래량의 4.5배 이상**

세 조건을 모두 만족해야 감지합니다. EMA 조건은 사용하지 않습니다. 미완성 봉의 고가·현재가·누적 거래량을 사용하므로 봉이 마감되기 전에는 조건이 달라질 수 있습니다. 거래량은 Binance Kline API의 기초자산 수량(base-asset volume)입니다.

## 앱 기능

- 글래스모피즘 스타일의 어두운 UI
- 매시간 50분 검사
- 화면을 닫아도 실행되는 foreground service 및 상시 알림
- 최근 검사 시각, 검사한 종목 수, 조건 충족 종목 수, 실패 수 표시
- 실시간 검사 진행률 표시: 완료 종목 수 / 전체 종목 수 및 퍼센트
- 최근 검사 기록만 간단히 저장 (최근 5개 기록)
- 조건 충족 종목별 현재가, 고가 상승률, 현재가 상승률, 거래량 배수 표시
- 종목별 **거래하기** 버튼으로 바이낸스 선물 차트 열기
- 감지 시 휴대폰 알림
- 자동 주문/매매는 하지 않음

## GitHub에서 APK 만들기

이 프로젝트에는 GitHub Actions 빌드 워크플로가 포함되어 있습니다.

1. ZIP 파일을 PC에서 압축 해제합니다.
2. GitHub 저장소 `https://github.com/tnehdl02/binanace`를 엽니다.
3. 수정할 파일들을 저장소의 같은 경로에 업로드/교체합니다. `app` 폴더, `README.md` 등 프로젝트 파일이 저장소 루트에 있어야 합니다.
4. `.github/workflows/build-apk.yml`도 포함되어 있는지 확인합니다. 브라우저에서 숨김 폴더가 보이지 않으면 해당 파일은 GitHub에서 직접 경로를 만들어 업로드해야 할 수 있습니다.
5. 변경 사항을 `main` 브랜치에 커밋합니다.
6. 저장소의 **Actions** 탭에서 **Build Android APK** 워크플로가 성공했는지 확인합니다.
7. 성공한 실행을 열고 **Artifacts**에서 `binance-phone-scanner-debug-apk`를 다운로드합니다.
8. 아티팩트 ZIP을 풀고 `app-debug.apk`를 휴대폰에 옮겨 설치합니다.
9. 앱에서 알림 권한을 허용하고 **감시 시작**을 누릅니다.

APK는 테스트용 debug APK입니다. Play 스토어 배포용 서명 APK가 아닙니다.

## 사용 및 주의사항

- 감시를 시작하면 상시 알림이 표시됩니다. 앱 또는 알림의 `감시 중지`로 중지할 수 있습니다.
- 감지 종목이 없으면 앱 로그에 `조건 충족 종목 없음`으로 남습니다. 검사 실패는 성공한 검사와 구분해 기록합니다. 검사 중에는 완료된 코인 수와 퍼센트가 갱신됩니다.
- Android 설정에서 앱 배터리 사용을 `제한 없음` 또는 `최적화 제외`로 설정하면 백그라운드 유지에 도움이 됩니다. 메뉴 이름은 기기마다 다를 수 있습니다.
- 강제 종료, 재부팅, 인터넷 단절, 제조사별 배터리 관리 또는 Binance API 제한이 발생하면 감시가 중단되거나 일부 종목 검사가 실패할 수 있습니다. 이 앱은 24시간 무중단 실행을 보장하지 않습니다.
- 재부팅 후에는 앱을 다시 열어 감시를 시작해야 합니다.
- 이 앱은 공개 시세를 읽을 뿐 주문을 실행하지 않습니다.

## v1.5 업데이트 (15분봉 + 1시간봉 감시, 개별 알림, 종목명 복사)
- 감시가 2개로 늘었습니다. 조건(고가 +5% / 현재가 +4% / 거래량 4.5배)은 같고, 봉 기준만 다릅니다.
  - 15분봉: 매시 13 · 28 · 43 · 58분 (각 15분봉 마감 2분 전, 한국 시간)
  - 1시간봉: 매시 50분 (1시간봉 마감 10분 전, 한국 시간)
  - 시간은 `ScannerService.kt` 맨 위 `ScanTimeframe`의 `scanMinutes`에서 바꿀 수 있습니다.
- 화면은 15분봉/1시간봉 구역으로 나뉘며, 요약·감지 종목·검사 기록이 각각 따로 표시됩니다.
- "거래하기" 버튼 대신 **종목명 복사** 버튼이 생겼습니다. 복사한 뒤 바이낸스 앱 검색창에 붙여넣으세요.
- 급등 알림은 종목마다 **개별 알림**으로 뜨고(제목에 `[15분봉]` 또는 `[1시간봉]` 표시), 알림에 **종목명 복사** 버튼이 있습니다.
- 상단 상시 알림에는 마지막 검사 요약과 다음 검사 시각만 표시됩니다.
- 아직 GitHub Actions 빌드와 실제 기기에서 확인하지 않았습니다.

## v1.6 업데이트 (Doze 절전 모드 대응)
- 검사 대기 방식을 `Thread.sleep`에서 안드로이드 알람(`AlarmManager`, 정확한 알람 + 절전 중 허용)으로 바꿨습니다. 폰이 깊은 절전(Doze)에 들어가 있어도 정해진 시각에 깨어나 검사합니다.
- 검사하는 동안에는 CPU가 꺼지지 않도록 WakeLock을 잡고, 끝나면 바로 해제합니다.
- 앱 화면을 스와이프로 닫거나 서비스가 시스템에 의해 종료돼도, 남아 있는 알람이 다음 검사 시각에 서비스를 다시 깨웁니다. (설정에서 강제 종료한 경우는 제외)
- 감시 중지를 누르면 예약된 알람이 모두 취소됩니다.
- 절전 중 알람은 시스템이 앱당 약 9분에 한 번으로 제한할 수 있습니다. `백그라운드 유지 설정`에서 배터리 최적화 제외를 해두면 영향이 줄어듭니다.
- 아직 실제 기기에서 확인하지 않았습니다.

## v1.7 업데이트 (봉별 조건 분리)
- 15분봉: 고가 시가 대비 +4% 이상 / 현재가 시가 대비 +3% 이상 / 거래량 직전 봉의 4.5배 이상
- 1시간봉: 고가 시가 대비 +5% 이상 / 현재가 시가 대비 +4% 이상 / 거래량 직전 봉의 4.5배 이상
- 조건 숫자는 `ScannerService.kt` 맨 위 `ScanTimeframe`에서 봉마다 따로 바꿀 수 있습니다.

## v1.8 업데이트 (봉별 감시 분리 + 5일 기록)
- 15분봉 감시와 1시간봉 감시를 **각각 따로 켜고 끌 수** 있습니다. 한쪽만 켜도 되고 둘 다 켜도 됩니다. 켜진 감시가 하나도 없으면 서비스가 자동으로 종료됩니다.
- 상단 알림의 `감시 중지` 버튼은 켜져 있는 모든 감시를 한 번에 끕니다.
- 각 감시 카드의 **기록 확인** 버튼으로 별도 화면을 엽니다.
  - 최근 5일 동안의 검사 결과가 이 휴대폰에 저장됩니다(봉별 파일 `history_m15.jsonl`, `history_h1.jsonl`). 5일이 지난 기록은 새 검사가 저장될 때 자동으로 지워집니다.
  - 요약(검사 횟수, 감지 횟수), 종목별 감지 횟수, 감지 기록(최신순), 최근 검사 로그를 볼 수 있습니다. 종목을 누르면 이름이 복사됩니다.
- 메인 화면 아래쪽의 "최근 검사 기록" 카드는 기록 확인 화면으로 옮겼습니다.
- 앱을 삭제하면 기록도 함께 지워집니다.
- 아직 GitHub Actions 빌드와 실제 기기에서 확인하지 않았습니다.

## v1.9 업데이트 (손절 여부 + 5일 고점 추적)
- 감지된 종목마다 **손절선 = 감지된 봉의 저가**를 저장하고, 감지 직후부터 5일 동안 1분봉으로 가격을 따라갑니다.
  - 손절 여부: 이후 1분봉 중 저가가 손절선 아래로 내려간 첫 시각을 기록합니다.
  - 5일 고점: 감지 후 5일 안의 최고가를 손절과 상관없이 기록합니다(손절이 없었다는 가정). 손절이 발생했다면 손절 전 고점도 함께 기록합니다.
  - 진입가는 감지 시점의 현재가이고, 고점·손절선 % 는 진입가 대비입니다.
- 검사가 끝날 때마다 기존 감지 종목의 추적 결과가 자동으로 갱신됩니다. 감시를 꺼 둔 동안에는 기록 확인 화면의 **추적 결과 새로고침** 버튼으로 갱신할 수 있습니다.
- 기록 확인 화면: 요약에 추적 결과(손절 발생/없음 건수, 평균·최대 고점), 종목별 손절 횟수와 평균 고점, 감지 건마다 손절선·손절 여부·5일 고점이 표시됩니다.
- 한계: 1분봉 안에서 저가와 고가 중 무엇이 먼저였는지는 알 수 없어서, 손절선을 깬 1분봉은 손절로 계산하고 그 봉의 고가는 "손절 전 고점"에 넣지 않습니다. v1.9 이전에 저장된 기록은 추적 정보가 없습니다.
